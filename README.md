## 🚀 Featured projects

### [Crewterm](https://github.com/mesutozansoftware/Crewterm)
Run Claude Code, Codex and other AI coding agents side by side in one window — as a team.
Agents message each other, split work on a shared task board, and each one gets its own git worktree so parallel edits never collide.

`Electron` · `Node.js` · `MCP` · `xterm.js` · macOS & Windows

### [GloShort](https://github.com/mesutozansoftware/GloShort)
A lightweight, cross-platform global hotkey manager. Bind system-wide shortcuts to terminal commands, URLs or apps, with folders, import/export and launch-at-login.

`Swift` · `Go` · `Python` · macOS, Windows & Linux

### [nanolimiter](https://github.com/mesutozansoftware/nanolimiter)
A tiny reverse proxy that shields your backend from rate-limit abuse and request floods. Token-bucket + sliding-window limits, automatic IP bans, a live web dashboard and an interactive console — in a single binary that idles at ~8 MB of RAM.

`Go` · Linux, Windows & macOS
